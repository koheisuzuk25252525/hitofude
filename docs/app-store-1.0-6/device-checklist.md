# ヒトフデ 1.0（6）— 最後の実機確認

既に **同じ1.0（6）** で確認済みの項目は、結果を書くだけで構いません。今回のコード・Webテストは実機操作の代わりにはなりません。警告修正版 `5086f9a` の実機結果とは分けます。

端末：＿＿＿＿　iOS：＿＿＿＿　アプリ内表示：1.0（6）　確認日：＿＿＿＿

| 確認 | 合格の目安 | 結果 |
|---|---|---|
| はじめてのプレイ | 初回の3マス→4×4の説明を終えて通常問題へ進める。初回確認には未プレイ端末やシミュレーターを使い、記録のある自分のアプリを削除しない。 | 未記録 |
| 通常プレイ・完成 | 指なぞり／マスタップ、通常ヒント、やり直しを試し、一問完成。「もう一問」で次へ、「今日はここまで」で完成盤面へ戻る。 | 未記録 |
| 保存・中断 | 数マス進めてホーム画面へ戻り、再開。アプリを終了して開き直しても進捗が残り、中断時間がプレイ時間に加算されない。 | 未記録 |
| 難易度と表示 | 各難易度が開き、難しい盤面の生成から戻れる。iPhone・iPad、横画面・文字拡大でも必要なボタンへ届く。 | 未記録 |
| 広告の完了 | TestFlightのテスト広告を使用。通常ヒントを使い切って「道案内」から広告を見て、次の数字まで最大6マスの案内が一度だけ付く。 | 未記録 |
| 広告の中断・失敗 | 報酬獲得前の終了、読み込みキャンセル、通信失敗では新しい案内が付かず、通常ゲームを続けられる。通信を戻すと再試行できる。 | 未記録 |
| 音・復帰 | アプリ内消音と端末の消音設定を確認。広告や別画面から戻って操作できる。 | 未記録 |
| 手紙の送受信 | 「…」→「一筆の手紙」で作成し、別端末で受け取る。完成後に本文が正しく見える。「解かずに手紙を読む」も動く。閉じると元のパズルへ戻る。 | 未記録 |
| インストールの違い | 入れていない端末ではWebで読める。入れている端末ではメッセージアプリ中のリンク／「アプリでこの手紙を開く」から同じ手紙を開ける。ブラウザの設定によりWebに残る場合も、Webで読める。 | 未記録 |
| 計測・広告設定 | 任意計測を断っても遊べる。広告のプライバシー設定を開ける。日本で「現在の地域では、変更できる広告の同意設定はありません」と出ること自体は異常ではない。 | 未記録 |

広告の実配信・報酬・音・Universal Linksは、シミュレーターの画面撮影やビルド成功だけで確認済みとはしません。テスト広告のクリックや本番広告の自己視聴を求めるチェックではありません。
