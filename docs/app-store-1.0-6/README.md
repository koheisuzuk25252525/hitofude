## プライバシー申告で残る具体的な確認

公式Google Mobile Ads 12.14.0のSDKマニフェストには、デバイスIDを「トラッキングに使用」とする宣言があります。これだけでヒトフデの実際の動作を断定はできませんが、アプリ側の「トラッキングなし」という宣言や非パーソナライズ設定だけを根拠に回答を確定できません。実際の1.0（6）のArchive Privacy ReportとAdMob設定を照合して確定してください。公式SDKの取得・ハッシュ照合・項目整理までは実施済みです。

根拠は [privacy-audit.md](privacy-audit.md) と `sdk-manifests/` に保存しました。この確認だけを理由にATTや新ビルドを追加したわけではありません。

## 残る確認

1. **実機の広告・音・リンク操作。** ビルド成功やWebの自動テストと区別します。同じ公開候補で既に確認した箇所は無条件にやり直す必要はありません。
2. **App Store Connectの登録。** この環境に管理画面への接続はありません。用意した文面を貼り付け、実際のArchive・SDK設定とプライバシー申告を照合してから提出します。
3. **公開URLが端末で開くこと。** この環境からGitHub Pagesへの直接HTTP接続はネットワーク制限があります。公開ソースとデプロイ成功の確認を、端末での通信確認と混同していません。
4. **ストア画像の最終目視確認。** シミュレーター撮影の結果は別資料に記録します。アップロード前に画像の内容・サイズを確認します。

App Storeの実URLを設定する作業は、そのページが公開された時点で行います。未公開のストアURLを推測して埋めていません。
