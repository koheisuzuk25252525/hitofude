# ヒトフデ — SwiftUI版

iOS 17以降、iPhone / iPad向けのネイティブアプリです。画面はSwiftUI、問題生成はApple標準のJavaScriptCoreを使い、通信せず端末内で動きます。WebViewは使用していません。任意参加の利用状況計測にはFirebase Analyticsを使います。計測は初期オフで、問題生成とプレイは引き続きオフラインで動きます。

## Xcodeで遊ぶ

1. MacのXcode 16以降で `ios/Hitofude.xcodeproj` を開く。
2. Schemeで **Hitofude**、実行先でインストール済みの **iPhone Simulator** を選ぶ。
3. **⌘R** で起動。未完了なら横一列3マス→4×4の必須チュートリアルが表示されます。
4. 1から上下左右になぞるか、マスを順番にタップします。数字のマスをその順番に通り、全マスを通るとクリアです。チュートリアル後は保存した通常問題を再開し、保存がなければ5×5の「さくっと1問」へ進みます。

実機で試す場合は、アプリターゲットの **Signing & Capabilities → Team** で自分のApple IDのチームを選び、Bundle Identifierの `com.example.hitofude` を自分用の一意な値に変更します。接続したiPhoneを実行先に選び、必要に応じて端末のDeveloper Modeを有効にして実行してください。Simulatorではチーム設定は不要です。

## 実装内容

- 練習、きょうの1問、やさしい、ふつう、むずかしい、鬼
- 指なぞり・タップ・ひとつ前のマスへの後戻り
- 数字と通過順序のチェック、ヒント3回、取り消し、やり直し
- タイマー、難易度ごとのベスト記録、練習完了と今日の結果の端末内保存
- クリア表示、結果テキストの共有、触覚フィードバック
- ライト／ダーク、VoiceOver用のマスの説明、画面サイズに合わせた盤面
- バックグラウンドでの問題生成とエラー時の再試行
- 盤面・経路・残りヒント・経過時間・対戦相手の自動保存と復元
- バックグラウンド／非アクティブ時の一時停止（中断時間を除外）
- 同じ問題・相手のタイムを共有する挑戦リンク、勝敗表示、再挑戦

日付seedは端末のローカル日付を使い、Web版と同じYYYYMMDDです。同じseed・難易度ではWeb版と同じ問題になります。効果音はWeb版に合わせて端末内で合成します。音声読み上げは含めていません。Web版のlocalStorageは引き継ぎません。AppIconとプライバシーマニフェストは同梱しています。署名と配布には所有者の設定が必要です。詳細は [TESTFLIGHT.md](TESTFLIGHT.md) を参照してください。

## 起動してすぐ1問

未完了なら横一列3マス（数字は1と3のみ）でなぞる操作を覚え、次に4×4で「数字は、そのマスを何番目に通るか」を体験します。2段階ともクリアするまで通常画面へは進めません。更新前のユーザーも一度体験し、通常問題の保存は維持します。「？」から練習に移るボタンはありません。「さくっと1問」はeasyと同じ生成仕様で、Webとのseed互換性・対戦リンク・ベスト記録は共通です。解く時間の保証はなく、30秒〜2分で解けるかはプレイテストで確認が必要です。

未クリアの保存問題があれば難易度や対戦状態を含めて続きを優先します。クリア済みの画面は次回起動時に新しいさくっと1問へ進みます。達成履歴・ベストは維持します。右上の「…」から「別の問題」を押すと、同じ難易度の新しい問題へ切り替えます。難易度は盤面の上、記録・対戦は右上の「…」（遊び方・記録・設定）にあります。

最後に使ってから72時間以上空くと、星・葉・月のアイコンを添えた「おかえりなさい」が盤面の上に現れます。新規起動とバックグラウンド復帰の両方が対象です。日数や連続記録を強調せず、通知・受け取り操作・プレイを遮る画面もありません。途中の問題は消さず、視差効果を減らす設定ではアニメーションを省きます。復帰後最初の通常問題クリアでは、線が一度だけ穏やかに光り、「また一筆、つながりました。」を結果に添えます。途中終了・再起動・やり直しを挟んでも次のクリアまで保持し、練習では消費しません。追加の音や待ち時間はなく、いつものクリア音と消音設定を使います。最終利用日時と演出の待機状態は端末内だけに保存します。

## 毎日の達成とごほうび

右上の「…」（遊び方・記録・設定）を開き「今月のひとふで」を押すと、月を切り替えられる達成カレンダーと配色の設定が開きます。クリアした日は点、当日分の「きょうの1問」を解いた日はチェックが付きます。月10問が目標で、連続日数は問いません。

練習以外の新しい問題を初めてクリアした月に1問と数えます。同じサイズ・難易度・seedの再クリアは月をまたいでも重複カウントしません。同じ盤面になるdailyとmediumも重複しません。ヒントを使ったクリアや対戦も対象です。前日分を翌日に解いた場合はクリア日に通常の1問として数えますが、当日のdaily達成チェックは付きません。

どこかの月に10問達成すると「夜空」の配色が解放されます。解放後にカレンダー画面で選べ、選択と解放状態は端末内に保存されます。翌月は問数が0から始まりますが、手に入れた配色は引き続き使えます。記録はこの機能の追加後から始まり、過去のベストタイムから達成履歴は推測しません。アプリ削除や端末間同期には対応しません。

## 保存と対戦

各有効手・取り消し・ヒント・やり直し・中断で、最後の1問をUserDefaultsに保存します。起動時に未クリアの盤面・経路・ヒント・時間・対戦相手を復元します。クリア済みなら新しいさくっと1問を始めます。古い日付の「きょうの1問」もそのまま復元し、画面に保存した日付を表示します。新しい難易度・対戦の開始成功時に保存対象が切り替わります。破損データや未対応の保存形式は安全に破棄し、通常の初期画面に戻ります。アプリ削除、端末変更、Web版との同期には対応していません。UserDefaultsの書き込みはOSが管理するため、突然の電源断直前までの保存は保証しません。

タイマーは最初の1手かヒントで開始し、非アクティブ・バックグラウンド時に停止、復帰時に再開します。終了から再起動までの時間も加算しません。

クリア後の「挑戦リンクを送る」で相手に共有し、相手はアプリの「リンクで対戦」に貼り付けます。難易度と相手のタイムを確認してから開始すると現在の問題が切り替わります。Web版と同じ `https://koheisuzuk25252525.github.io/hitofude/#c-e-1000-42` 形式を使います。リンクのタップはWeb版を開きます。iOSアプリへの自動遷移（Universal Links）は未設定です。

対戦はヒント各3回・一時停止可の自己申告タイムです。秒単位に四捨五入して勝敗を判定し、同秒なら引き分け。共有時間は0秒〜7日、seedはUInt32の範囲です。記録の認証や不正防止はありません。

## テスト

Xcodeで **⌘U**。XCTestは生成器17ケースの一意解・再現性、練習問題の不正操作・クリア・保存、ヒントの重複消費・復元・経路修正、取り消し、日付seed、保存・復元と中断時間の除外、クリア24時間後の記録・共有の不変性、壊れた保存データ、不正リンク、対戦の勝敗、軌跡補間、生成失敗と時間上限を検証します。

実機での具体的な確認項目と結果記録欄は [DEVICE_TESTING.md](DEVICE_TESTING.md) を参照してください。GitHub Actionsの **iOS tests** でもmacOS上のSimulatorでビルドとXCTestを実行します（mainおよび旧iOSブランチへのiOS変更push、PR、手動実行）。これは実機テストとは別です。

コマンドラインではMac上で、まず利用可能なSimulatorを確認します。

```sh
xcodebuild -project ios/Hitofude.xcodeproj -scheme Hitofude -showdestinations
xcodebuild -project ios/Hitofude.xcodeproj -scheme Hitofude \
  -destination 'platform=iOS Simulator,id=<表示されたSimulatorのID>' test
```

Linuxでも生成器のWeb/iOS一致を確認できます。

```sh
node tests/generator.test.mjs
node tests/native-generator.test.mjs
```

このLinuxクラウド環境にはXcode・Swiftがありません。iOSビルド・XCTest・署名なしRelease archiveはGitHub ActionsのmacOSで検証します。最新コミットのチェック結果を確認してください。iPhone実機での操作・VoiceOver・署名付きのアップロードは別途必要です。

## 生成器を更新するとき

`Resources/Generator.js` は `index.html` のseeded RNG / generator部分を同じ動作のまま同梱し、末尾の `nativePuzzle` でSwiftにJSONを返します。生成器を変更する場合は両方を同期し、上記NodeテストとXCTestを実行してください。生成器はJavaScriptCoreのローカルコンテキスト内で完結し、インターネット接続は不要です。

## 今回の操作改善

最初のヒントは2マス目を示し、「1」を触ったあとも目印を残します。ヒント表示中の重複消費を防ぎ、間違った経路を戻した同じ操作で次のマスに順番の目印を表示します。通常の案内は公開済みの数字と現在の歩数だけから計算します。完成した盤面は結果の上に残り、使わなくなった操作は隠します。「もう一問」は同じ難易度（練習後はeasy、daily後はmedium）へ進みます。ヘルプ・カレンダー・対戦入力の表示中もタイマーを止めます。

生成には協調的な20秒の上限があり、時間切れでは正解を妥協して作らず、同じseedの再試行またはeasyへ戻れます。成功時の乱数順・問題内容はWebと同じです。

## プレイ状況の計測とフィードバック

右上の「…」（遊び方・記録・設定）から任意参加の計測設定と、不具合・感想の報告文作成を開けます。Firebaseの登録・設定ファイル・DebugView・集計方法・計測の限界は [ANALYTICS.md](ANALYTICS.md) を参照してください。SDK追加後はXcodeが依存パッケージを解決するため、初回ビルドに通信が必要です。設定ファイルを追加しなくてもゲームとテストは動きます。

## 効果音と難易度

盤面の上は「難易度」と現在の選択を1行で表示します。タップすると「きょうの1問・やさしい・ふつう・むずかしい・鬼」のメニューが開きます。練習問題は「あそびかた」から開きます。

右上のスピーカーで効果音をオン／オフできます（初期オン、設定は再起動後も保存）。有効なマスを進むごとにWeb版と同じC3〜C7の音程で上昇し、クリア時に短いメロディーが鳴ります。音は端末内で合成し、音源ダウンロードは不要です。iPhoneの消音モードとメディア音量に従い、他アプリの音楽と混ぜて再生します。中断・問題切り替え・オフ操作では鳴っている音を止め、復帰時に過去の音を再生しません。読み上げは追加していません。


## 画面内に収める配置

通常のiPhone縦画面では、上のヘッダー・難易度と下の操作欄を確保し、残りの高さに合わせて盤面を縮めます。クリア後の「もう一問」は結果パネル内だけに表示し、クリア直後に半透明の結果パネルを盤面の上へ自動表示します。「もう一問」、挑戦リンク、結果共有、達成カレンダーを同じパネルから操作できます。右上の×で盤面へ戻り、下部の「結果を表示」で再表示できます。文字を大きくした場合や短い横画面では結果パネルの中だけをスクロールでき、「もう一問」と閉じるボタンは固定します。記録・配色・対戦入力・計測・不具合報告は右上の「…」にあります。極端に大きな文字や横向きの小さいウィンドウでは、盤面を読めない大きさに縮める代わりに上部をスクロール可能にし、操作欄は下に固定します。


## なぞり操作の応答

UIKitのタッチ履歴（coalesced touches）を直接受け取り、1回のイベントに含まれる曲がり角も順に判定します。座標履歴は描画用の状態から分離し、同じマス内の座標更新だけで盤面を再描画しないようにしています。高速移動で補間した複数マスはすべて順に判定し、1回の入力イベントの最後に経路を保存します。音と触覚もそのイベントの最後の有効手にまとめ、遅れてまとめて鳴らしません。指を離す前やバックグラウンド通知がなくても、そのイベントまでの進捗は保存済みです。

音の合成・音声セッションの準備・再生はメインスレッド外の専用actorで実行します。同じ音の波形を再利用し、遅れた効果音を後から連続再生しません。消音・中断より古い再生要求を捨て、再開後に過去の音が鳴らないようにしています。クリア時も操作欄の高さを維持し、盤面の位置が変わらないようにしています。


## 問題生成に失敗しても通常プレイを続ける

通常の「やさしい・ふつう・むずかしい・鬼」は、各16問の検証済み問題を同梱し、選択時に生成完了を待たず表示します。元の生成器の経路・数字・seedをそのまま保存したもので、難易度やWeb版との共有互換性は変わりません。用意済み問題の順番は難易度ごとに端末へ保存し、16問を一巡するまでは同じ同梱問題を繰り返しません。

表示後、次の問題を1つだけ低優先度・生成時間上限1.5秒で準備します。次の問題が準備できていればそれを使用し、生成が間に合わない・失敗した場合も同梱問題を使用します。先読み用の生成処理を複数同時に走らせません。

きょうの1問やseed指定の挑戦リンクは、同じ問題を再現するため別のseedに置き換えません。同梱seedなら即座に読み込み、それ以外は従来どおり生成し、失敗時は再試行の案内を出します。

同梱問題の更新は `node scripts/prepare-native-puzzles.mjs`。`node tests/native-generator.test.mjs` が64問すべてのWeb版との完全一致・一意解・生成時間ゼロでの読み込みを確認します。ヒントの仕様は変更していません。目印表示中の連打は追加消費しませんが、進む・取り消す操作で目印が消えた後の再要求は1回として数えます。

### 道案内と広告
通常ヒントの残数は「やり直す」でも維持します。0回になったら任意のリワード広告1回で、次の数字まで最大6マスを案内します。追加の広告で何度でも利用でき、案内済み区間の見直しは無料です。Google Mobile Ads SDKは12.14.0固定で、広告を見る操作まで開始しません。本番・テスト切替とUMP同意管理は [ADS_RELEASE.md](ADS_RELEASE.md) を参照してください。確認手順は [TESTFLIGHT.md](TESTFLIGHT.md) を参照してください。
