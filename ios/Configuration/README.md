# Firebase設定ファイルの置き場所

所有者のFirebase Consoleから取得した `GoogleService-Info.plist` を、このフォルダへコピーしてください。Xcodeにファイル参照を追加する必要はありません。ビルド時に存在する場合だけアプリへコピーします。

ファイルはGitの管理対象外です。ファイルがないCI・他の開発環境でもビルド・ゲームは動き、計測は無効です。Bundle IDが違うファイルを置いた場合は、誤送信を避けるためビルドを停止します。

サービスアカウントの秘密鍵をここに置かないでください。詳しくは [計測のセットアップ](../ANALYTICS.md) を参照してください。
